# 顶行二进制插槽活动实现计划
## 实施状态（2026-08-03）

本计划已完成并烧录验证，以下事实以当前固件为准：

- 第 401 关的实际流程为 `DETAIL -> INTRO -> LEARNING_ACTIVITY -> PLAY`；剧情页先介绍二进制，再进入训练。
- 训练题固定为十进制目标 `{4, 5, 2}`，使用实物底板最上方一行的四个槽位。
- 顶行从屏幕左到右对应物理槽位 `6 / 4 / 2 / 0`，权重为 `8 / 4 / 2 / 1`。
- 空槽显示并代表 `0`；任意积木放入槽位后显示并代表 `1`；UI 只绘制四个真实槽位，不再绘制 4×4 模拟板。
- 活动不进入正式 `play_mode`、不创建语音会话、不运行电路判题；底板 I2C 识别在活动期间以只读方式继续扫描，积木 OLED 保持空白。
- WS2812 仅高亮顶行四个槽位的端口；右键跳过进入正式组装，中键在答对后推进题目或开始组装。
- 已完成字库覆盖检查、`git diff --check`、ESP-IDF 增量构建和 `COM9` 烧录验证。


> **面向 AI 代理的工作者：** 必需子技能：使用 `superpowers:executing-plans` 按任务实现并验证。

**目标：** 在第 401 关正式搭电路前，用实物底板最上方一行的四个插槽完成三道二进制练习题；空槽表示 `0`，任意积木占位表示 `1`。

**架构：** 新增独立 `learning_activity` 模块保存第 401 关的题目、顶行槽位映射、实时位状态和完成状态。`app_ui` 只负责页面和按键流转；主循环在活动激活时只高亮顶行端口 LED，不启动 `play_mode`、电路判题或语音会话。

**技术栈：** ESP-IDF、C、LVGL、现有 `board_snapshot`、`board_mapping`、WS2812 输出任务。
